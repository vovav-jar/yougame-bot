# YouGame Notifier — сборка для хостинга

В этой папке только то, что нужно серверу: исходники бота, зависимости и пример настроек. Локальные тесты, диагностика, состояние и куки сюда не входят.

## Что нужно от хостинга

- Постоянно работающий Node.js-процесс (VPS, Railway, Render, Timeweb и т. п.), Node.js 22+.
- Публичный HTTPS-адрес: Telegram принимает вебхук только по HTTPS.
- Постоянный диск для папки `data` (иначе после перезапуска сбросятся выбранные разделы, прочитанные темы и куки).
- Серверлес-хостинги с коротким лимитом времени (Vercel, Netlify Functions) не подходят: бот держит планировщик и состояние.

## Установка

1. Загрузи содержимое этой папки на сервер (например в `/opt/yougame-bot`).
2. Создай `.env` из `.env.example` и заполни:

```
BOT_TOKEN=токен_от_BotFather
OWNER_ID=твой_telegram_id
WEBHOOK_URL=https://твой-домен/telegram
WEBHOOK_SECRET=случайная_строка
PORT=8080
YOUGAME_COOKIES_PATH=./data/yougame-cookies.json
YOUGAME_BROWSER_PROFILE=./data/browser-profile
```

`WEBHOOK_SECRET` — случайные буквы, цифры, `_` или `-` (до 256 символов), например `openssl rand -hex 32`. Если хостинг сам выдаёт порт, оставь его значение из панели в `PORT`. Если указать `WEBHOOK_URL` без пути (например `https://bot.example.com`), бот по умолчанию слушает `/telegram`.

3. Установи зависимости и запусти:

```
npm install --omit=dev
npm start
```

В логе должно появиться:

```
Бот @... запущен.
Вебхук: https://твой-домен/telegram (порт 8080, путь /telegram)
```

4. Проверь `https://твой-домен/health` (или корень `/`) — ответ `ok` означает, что процесс жив. После этого напиши боту `/start` в Telegram.

## Куки форума

Уведомления читаются только под твоим аккаунтом, а окна браузера на сервере нет. Поэтому сессию переносят с локальной машины:

1. На своём компьютере в папке `bot` выполни `npm run login` и войди на yougame.biz.
2. Скопируй файл `%USERPROFILE%\.yougame-mcp\cookies.json` на сервер в `data/yougame-cookies.json`.
3. Перезапусти бота и проверь в Telegram `/status` и `/alerts`.

Куки живут ограниченное время. Когда бот напишет, что сессия истекла, повтори вход локально и снова скопируй `cookies.json`. Команда `/login` на сервере бесполезна: там нет графического окна.

Если хостинг позволяет установить Chromium, бот сможет сам проходить антибот-проверку:

```
npx playwright install --with-deps chromium
```

Это не отменяет ручной вход: сессию аккаунта всё равно нужно периодически обновлять копированием куки.

## Обновление

Замени файлы в `src` на новые, затем:

```
npm install --omit=dev
npm start
```

Весь код бота лежит в `src`. Папки `data` и файл `.env` при обновлении не трогай.

## Вернуться на long polling

1. Убери `WEBHOOK_URL` из окружения и останови сервер.
2. На локальной машине в папке `bot` выполни `npm run webhook:off`.
3. Запусти локального бота через `npm start`.

Пока установлен вебхук, Telegram не отдаёт обновления через `getUpdates`, поэтому локальный long polling с тем же токеном работать не будет.

## Безопасность

- `.env`, `data/` и `cookies.json` дают доступ к боту и аккаунту форума. Не выкладывай их в публичный репозиторий и не передавай никому.
- `WEBHOOK_SECRET` обязателен: без него на адрес вебхука может постучаться кто угодно.
- Бот отвечает только владельцу в личных сообщениях.
